# Religions / Faiths

Modern religious and worldview options for character name generation. Faith often shapes given names, saint/prophet commemorations, theophoric forms, and whether a religious name is used in public life.

Writers may choose **None / Non-religious**, **Unspecified**, or **Other / Syncretic** when no single tradition fits.
